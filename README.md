# Ethan Bicycle Rush

Stadium cycling game with three courses, six missions, coin rewards, a bike upgrade shop, kits, emotes, a live course map and timed medals.

## GitHub
1. Extract this ZIP.
2. Create a GitHub repository.
3. Upload all extracted files to the repository root and commit.

## GitHub Pages
In repository Settings > Pages, select Deploy from a branch, main, and / (root), then Save.

## Vercel
Import the GitHub repository. Choose Other as the framework. Leave the build command empty and use . as the output directory.

## Local play
Open index.html in a modern browser, or serve this directory with python -m http.server 8000 and visit http://localhost:8000.

## Controls
Up / W: pedal. Down / S: brake. Shift: boost. Space: jump. P: pause. E: emote. Touch buttons are included.

Missions & shop opens Rider HQ. Progress saves in this browser only. There is no online multiplayer or cloud account system.

The stadium background is AI-generated. The cyclist is animated in 2D.
